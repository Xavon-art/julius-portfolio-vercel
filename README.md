# Julius Matro — Portfolio

Personal portfolio for Julius Matro, a software developer based in the Philippines building fast, reliable native and cross-platform software for Android, iOS, macOS, and the web.

## Stack

- [Next.js](https://nextjs.org) (App Router) + React 19
- Tailwind CSS v4
- framer-motion, lucide-react
- Deployed to Cloudflare Workers via `@opennextjs/cloudflare`

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint   # eslint
npm run build  # production build
```

## Deploy

```bash
npm run deploy
```

Builds with `opennextjs-cloudflare` and publishes to the live Worker.
